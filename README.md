# وين؟ — تكسي يبرود

مشروع ويب عربي RTL لخدمة طلب التكسي في يبرود، مع واجهة مهيأة للجوال، Supabase، الخرائط، الرحلات، المحادثات، وتدفق تفعيل الحسابات برمز مؤقت لمرة واحدة.

## البداية
1. راجع `docs/SETUP_AR.md` قبل النشر.
2. اضبط `config.js` بمفتاح Supabase العام فقط.
3. جهز قاعدة البيانات وانشر Edge Function على بيئة اختبار.
4. اختبر كل الحالات قبل استبدال الموقع الحالي.

## الأمن
- لا توجد في الأرشيف رموز تفعيل حقيقية أو مفاتيح خدمة.
- لا تستخدم `service_role` في المتصفح.
- رمز التفعيل مرتبط برقم هاتف ودور محدد ويستهلك ذريًا.
- SMS OTP يحتاج مزودًا منفصلًا وإعدادًا في Supabase.
